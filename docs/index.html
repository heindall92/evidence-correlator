            Cómo se usa

            1. Ejecuta la CLI: python3 -m proyecto run --dashboard-js docs/data/bundle.js.
            2. Abre docs/index.html directamente (funciona en file://) o publícalo en GitHub Pages.
            3. Para revisar otro paquete, pulsa Abrir o arrastra el fichero correlated_evidence_bundle.json a la ventana.
            4. En Custodia, Verificar ahora recalcula en el navegador todos los sellos SHA-256 y la raíz de Merkle.

            La verificación de referencia es la de la CLI: python3 -m proyecto verify paquete.json.

            Privacidad

            • La consola no hace ninguna petición de red: la política de seguridad de contenidos (CSP) bloquea cualquier conexión externa.
            • Fuentes, iconos y scripts están incluidos en el repositorio. No hay CDN, analítica ni cookies.
            • Los paquetes que abres se leen en memoria y no se guardan.
            • Solo se guardan tus preferencias (tema, acento, densidad) en el almacenamiento local del navegador.
